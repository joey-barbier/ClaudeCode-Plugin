Méthode et limites

Cloud non mesuré Les sessions cloud (Claude Code sur le web, fils de projet claude.ai) tournent dans des conteneurs éphémères : leurs transcripts disparaissent avec le conteneur. Leur consommation n'est donc pas dans ces chiffres, et elle n'est pas estimée. Les sessions Remote Control tournent sur la machine où elles sont lancées et sont comptées avec elle.

  • Source : chaque ligne assistant des fichiers .jsonl de ~/.claude/projects, sous-agents compris, champ message.usage.
  • Une même réponse apparaît sur plusieurs lignes : elle est comptée une fois, par couple message.id + requestId.
  • Les quatre compteurs sont ceux de l'API : entrée (non cachée), sortie, écriture de cache et lecture de cache. Le total les additionne tels quels, sans pondération de prix.
  • Le dernier jour s'arrête à l'heure de la mesure. Le choix de période ne peut pas sortir de la fenêtre mesurée.
  • Aucun coût n'est calculé : la page compte des tokens, pas des euros.
