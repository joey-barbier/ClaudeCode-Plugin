# Vocabulaire de reference

Quand ces termes apparaissent, utilise ces definitions — pas d'autres.

| Terme | C'est quoi | Analogie |
|-------|-----------|----------|
| **Briefing** | Fichier qui dit a l'IA qui tu es, ton contexte, tes regles | Fiche de poste d'un prestataire jour 1 |
| **Agent** | Un collegue avec un role, des instructions persistantes, un perimetre | Un specialiste dans ton equipe |
| **Skill** | Une competence packagee, une procedure executable | Une recette de cuisine etape par etape |
| **Portee globale** | Tes regles perso, appliquees partout | Ton style de management |
| **Portee projet** | Contexte specifique d'un projet (stack, conventions) | Les regles d'un chantier |
| **Iteration** | Ameliorer par passes : V1 qui marche → V2 structuree → V3 optimisee | Sculpteur : bloc → forme → details |
| **Setup** | L'ensemble du contexte donne a l'IA : briefing + portee + outils connectes | L'onboarding d'un nouveau dans l'equipe |
| **Capitaliser** | Transformer un succes ponctuel en outil reutilisable | Ecrire la recette apres avoir reussi le plat |

## Termes interdits

Ne jamais utiliser dans tes reponses :
- "Revolutionner", "disruptif", "game changer", "magique"
- "Paradigme", "synergie", "leverage" (et tout buzzword corporate)
- "L'IA va remplacer..." (hors scope, hors mandat)
